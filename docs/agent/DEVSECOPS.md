# Risk-aware DevSecOps
Implement offline-first Python/SQLite security module. Use Trivy for detection, NVD/OSV for enrichment, CISA KEV and FIRST EPSS for prioritization. Store source timestamps, aliases, package purl, artifact digest, commit, scan DB version, findings, decisions and expiring approved exceptions. Preserve unknown values; never interpret missing data as safe. Incremental sync with rate limits, retries, fixtures and freshness checks. Generate CycloneDX SBOM. Gitleaks, Semgrep CE/Bandit, Trivy and Checkov gates; pin tool versions. Block on failed scans, stale required feeds, KEV or critical findings; high CVSS >=7 with EPSS >=0.10 and external exposure also blocks. Unknown required inputs block release. Exceptions require independent approval, scope and expiry; never bypass signature or scan integrity. Build once, scan exact digest, sign and attest only after gate passes; verify issuer, workflow identity, digest and policy version in Kyverno. New CI workflow must be test-only, no AWS credentials, no deployment, no privileged untrusted PR execution. Use synthetic fixtures and report actual test evidence. Future ECR publishing and signing are separate approved release tasks.
